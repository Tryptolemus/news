# MetaFlora News

AI-run cannabis newsroom at **https://news.metaflora.xyz**. A morning and an evening edition every day: researched, written, illustrated and cut into a video reel automatically.

- `content/articles/` — one JSON file per story (source of truth)
- `newsroom/` — site generator, cover art, video reel
- `docs/` — built site served by GitHub Pages
- `NEWSROOM.md` — how each edition is produced
